# DAVINCI CODE 개인정보 처리방침

시행일: 2026년 12월 1일 · 운영: Team STIM

DAVINCI CODE(이하 "앱")는 게임을 하는 데 꼭 필요한 정보만 수집해요.

## 1. 수집하는 정보

| 항목 | 목적 | 보관 위치 | 보관 기간 |
| --- | --- | --- | --- |
| 닉네임, 캐릭터 번호 | 다른 사람에게 표시 | 서버 메모리 (접속 중에만) | 접속 종료 시 삭제 |
| 기기 ID (앱이 처음 실행될 때 만든 임의의 값) | 끊겼을 때 재접속 | 사용자 PC, 서버 메모리 (접속 중에만) | 접속 종료 시 서버에서 삭제 |
| 신고 내용과 신고된 사람의 최근 채팅 | 운영 정책 위반 확인 | 서버 `data/reports.log` | 처리 후 90일 |
| 접속 IP와 접속 시각 | 서버 운영·장애 대응 | 서버 로그 (`data/logs`, 날짜별 파일) | 30일 |

- **채팅 내용은 저장하지 않아요.** 서버 메모리에 최근 채팅 일부가 잠깐 머물다가 지워지고, 신고가 들어온 경우에만 신고 기록에 남아요.
- **게임 결과(전적·순위)는 서버에 저장하지 않아요.**
- 이름, 연락처, 위치, 사진, 결제 정보 등은 수집하지 않아요.
- 광고, 외부 분석 도구, 제3자 SDK를 쓰지 않아요.

## 2. 사용자 PC에 저장하는 정보

설정 폴더(Windows: `%APPDATA%\DavinciCode`)에 닉네임, 캐릭터, 소리 설정, 최근 접속한 서버, 차단 목록, 기기 ID, 오류 기록(`logs/crash.log`)을 저장해요. 앱을 지울 때 이 폴더를 지우면 모두 사라져요.

## 3. 제3자 제공

법령에 따른 요청이 있는 경우를 빼고는 누구에게도 제공하지 않아요.

신고 기록 확인이나 삭제를 원하면 아래 연락처로 닉네임을 알려 주세요. 7일 안에 처리해 드려요.

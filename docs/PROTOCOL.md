# 통신 규약 (프로토콜 버전 3)

> 버전 3 (앱 1.3.0): AI(`ADD_BOT`), 랭킹(`RANKING`), 레이팅, 조커 켜고 끄기를 없앴다 (조커는 항상 쓴다). 게임을 시작하면 `SETUP` 단계에서 모두 `PICK`으로 시작 패의 검정 개수를 고른다. 버전 2 이하 앱이 접속하면 서버가 업데이트 안내와 함께 거절한다.
>
> 버전 2 (앱 1.2.0): 엿보기(`PEEK`)를 없애고 `PROFILE`(닉네임·캐릭터 바꾸기)을 더했다. `CREATE`/`SETTINGS`/`ROOM`/`STATE`/`LOBBY`에서 엿보기 필드가 빠졌다. 버전 1 앱이 접속하면 서버가 업데이트 안내와 함께 거절한다.

- TCP 소켓, `DataOutputStream.writeUTF` / `DataInputStream.readUTF`로 한 메시지씩 주고받는다 (수업 코드와 같은 방식).
- 메시지 = `명령어` + 탭(`\t`) + `필드1` + 탭 + `필드2` …
- 목록 필드: 레코드를 `\u001E`(RS)로, 레코드 안의 값을 `\u001F`(US)로 나눈다.
- 사용자가 입력한 글자(채팅, 방 제목, 닉네임)는 제어 문자를 지워서 구분자와 절대 섞이지 않는다 (`Proto.clean`).
- 같은 네트워크 검색: UDP 30099 포트로 `DAVINCICODE?`를 브로드캐스트하면 서버가 `DAVINCICODE!\t이름\t포트\t접속자\t프로토콜\t버전`으로 답한다.

## 웹 브라우저 (같은 포트)

서버는 연결의 첫 바이트로 상대를 구분한다 (`server/Gate.java`).

| 첫 바이트 | 상대 | 처리 |
| --- | --- | --- |
| `0x00` (writeUTF의 길이 앞자리) | PC 앱 | `readUTF`/`writeUTF`로 게임 메시지 |
| 영문 대문자 (`GET /…`) | 웹 브라우저 | HTTP 요청으로 읽는다 |

| HTTP 요청 | 응답 |
| --- | --- |
| `GET /` (또는 `/index.html`) | 웹 게임 화면. 보안 헤더(CSP, nosniff, frame-ancestors 'none') 포함 |
| `GET /app.js`, `/proto.js`, `/style.css`, `/icon-192.png`, `/icon-512.png`, `/manifest.webmanifest` | 웹 게임 파일 (JAR 안의 `stim/davincicode/web/`에서 읽는다) |
| `GET /health` | `{"ok":true,"name":"…","online":N}` (클라우드 상태 확인용) |
| `GET /ws` + `Upgrade: websocket` | WebSocket 연결 (RFC 6455). 이후 메시지는 PC 앱과 **완전히 같은 한 줄**을 텍스트 프레임 하나에 담는다 |
| 그 밖의 경로 | 404 (정해진 파일 목록만 보내므로 폴더 밖 파일은 절대 나가지 않는다) |

- 브라우저가 보내는 프레임은 반드시 마스크되어야 하고, 아니면 연결을 끊는다. 쪼개진 프레임(continuation), ping/pong, close를 처리하고 메시지 하나는 64KB까지만 받는다.
- 웹 클라이언트도 10초마다 `PING`을 보내고, 기기 ID(이 브라우저에서 만든 임의의 값)와 닉네임으로 재접속한다.
- HTTPS 사이트로 서비스하면 웹 화면이 자동으로 `wss://`로 연결한다 (TLS는 앞에 둔 리버스 프록시가 처리).

## 타일 표기와 정보 은닉

`[uid][색][숫자|J|?][*]` — 예: `17B5*`(공개된 검정 5), `3W?`(숫자를 모르는 흰 타일).

- uid는 판마다 무작위로 섞어 붙인 번호라서 숫자와 관계가 없다.
- `Game.snapshot(viewer)` 한 곳에서만 STATE를 만든다. 주인 본인과 공개된 타일만 숫자가 들어간다. 관전자(viewer 0)는 공개된 타일만 본다.
- 시작 패를 고르는 동안 다른 사람이 고른 개수는 `?`(골랐음)로만 보낸다. 나눠 준 뒤에는 타일 색으로 어차피 보이므로 숫자로 보낸다.
- 게임이 끝나면 모든 타일을 공개한 STATE를 보낸다.

## 시간 제한과 연결 끊김

- 단계마다 제한 시간(방 설정, 무제한 가능). 지나면 서버가 대신 진행: 가져오기→무작위 색, 추리→틀린 것으로, 계속→멈추기.
- 시간 초과로 대신 가져온 경우 추리 시간은 15초.
- 시작 패 고르기는 방 설정과 관계없이 20초. 지나면 안 고른 사람은 동전 던지듯 임의로 정한다. 고르는 중에 나가면 그 자리만 빠지고, 1명만 남으면 바로 끝난다.
- 게임 중 연결이 끊기면 자리를 60초 동안 지키고(그동안 차례가 오면 최대 20초 뒤 자동 진행), 같은 기기·닉네임으로 다시 접속하면 이어서 한다. 60초가 지나면 기권.
- 한 연결이 초당 40개 넘게 보내면 도배로 보고 끊는다. 채팅은 5초에 5개까지.
